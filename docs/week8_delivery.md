# 第八周交付与复核说明

## 交付范围

干净工程目录保留第 1–2 周的历史环境与抓包说明、第 3–6 周关键实验脚本和恢复结果、第 7 周 Streamlit 应用及测试、第 8 周报告和演示文稿。原始归档包、旧版重复代码、虚拟环境、缓存和中间序列数组不放入精简目录；它们在原工作区保留，未被删除。

## Windows 启动

在工程根目录的 PowerShell 中运行 `./setup_windows.ps1` 安装依赖，再运行 `./week7/run_web.ps1`。启动成功后访问 [http://localhost:8501](http://localhost:8501)。这是本机网址，只有服务在这台电脑上运行时才有效，不是公网网址。

## 自动化验收

执行 `./.venv/Scripts/python.exe -m pytest week7/tests -q`。测试覆盖数据文件和字段、独立 Streamlit 进程启动、HTTP 健康与首页，以及预测、异常、根因、数据浏览等页面交互。当前工作区验收结果：9 passed。

## 实验边界

当前恢复材料中没有 `DLPRB_train_0w-5w.csv`，仅有清洗和归一化数据。因此已恢复的 Week 3–6 历史结果可复核、系统可启动，但原始数据起点的完整重跑需要另行提供该 CSV。`run_all.ps1` 会在原始文件缺失时明确停止，避免无意覆盖历史结果。

统计 3σ 和 IQR 的零计数来自每时刻 2880 个 KPI 的全网均值，该均值序列没有越过统计阈值；不表示每个 KPI 都无异常。Week 6 的 26、31、17 和 40 为无监督候选数，没有真实故障标签。根因候选排名基于异常/正常组差异和与异常标记的相关性，并非因果证明。
